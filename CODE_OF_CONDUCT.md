# Code of conduct

NotchUser follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and respectful, accept feedback gracefully, and focus on what's best for the people using NotchUser. Harassment, insults, and personal or political attacks aren't accepted in issues, pull requests, discussions or anywhere else the project lives.

## Reporting

If someone breaks these rules, report it privately through the repository's **[Security](https://github.com/Magnumja/NotchUser/security) tab → Report a vulnerability** (mark it as a conduct report), or open an issue titled **"Conduct contact"** with no details and you'll be given a private channel. Reports are handled confidentially.

The maintainer may remove comments, commits or issues, or block anyone who doesn't follow this code.
